# NUTTIN' — Website

One-page brand site for **NUTTIN' Trail Mix** (Nuttin' Boring Here.). Static HTML/CSS/JS, no build step.

- `index.html` — all sections: Home, Our Story, Our Mix, Why NUTTIN', Watch, Shop, Find Us
- `styles.css` — brand tokens (Brown #3A2416, Orange #FF8A00, Cream #FFF7E8; Baloo 2 / Balsamiq Sans / Poppins)
- `main.js` — mobile menu, scroll reveal, active nav, ingredient illustrations, video tabs
- `assets/` — product jar images (WebP) and the three ad videos

Preview locally: `npx serve .` (or any static server). Deployed on Vercel from the `main` branch.
